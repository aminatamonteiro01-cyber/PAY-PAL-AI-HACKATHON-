PayPal AI Hackathon Project

About the Project
An intelligent AI agent integrated with the PayPal Sandbox Orders API to securely and autonomously process transactions and manage checkout flows in real-time.

## Key Features
- AI-Driven Intention Processing:Uses advanced LLMs to evaluate user requests and decide when a transaction is required.
- PayPal Sandbox Integration:** Programmatically generates orders and approval links using the official PayPal Checkout SDK.
- Secure & Autonomous:** Built for agentic commerce applications.

Tech Stack
-Backend:Node.js & Express
-Payments:PayPal Checkout Server SDK (Sandbox Environment)
-Artificial Intelligence:OpenAI API
